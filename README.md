# Amazon scraper

This project started as part of practicing python and web scraping.


## Repository details

__What can you get from amazon_reviews.ipynb?__

Reviews from a specific product.

- Working with css selectors & find/find_all
  - author
  - rating
  - title
  - body
  - date
  - review
  - url

__What can you get from amazon_scraper.ipynb?__

Data from a specific product.

- Title
- Rating
- Price
- Image
- Description

__What can you get from amazon_reviews.py & amazon_scraper.py?__

Basically what you get from amazon_reviews.ipynb and amazon_scraper.ipynb but as a script. You can save the data as a **CSV** file. (Make sure to change the path).

__What can you get from product_listing.py?__

Paste the url of a searched product and get the data in a **CSV**:

- Title
- Price
- Rating
- Image
- Description
- URL

Examples of what you can get are amz.csv and headphones.csv
